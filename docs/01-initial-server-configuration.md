# 01 – Initial Server Configuration

## 1. Objective

The objective of this stage is to prepare the Windows Server 2025 environment for Active Directory Domain Services (AD DS) deployment.

Before installing server roles, the server must have a clear identity and a reliable network configuration.

## 2. Planned Configuration

| Component | Target Configuration |
|---|---|
| Operating System | Windows Server 2025 |
| Server Name | DC01 |
| Domain Name | corp.test |
| Server Role | Domain Controller |
| Time Zone | Adelaide (ACDT/ACST) |

## 3. Implementation

This section will document the following configuration tasks:

- Rename the server.
- Configure the system time zone.
- Check Windows Update status.
- Review the current network configuration.
