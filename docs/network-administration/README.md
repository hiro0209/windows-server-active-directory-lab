# Network Administration

## Overview

This directory contains practical exercises related to Windows network administration.

It focuses on examining network configurations, understanding command outputs, and verifying basic network functionality in a Windows Server 2025 and Windows 11 lab environment.

## Scope

| Area | Description |
|---|---|
| IP Configuration | Checking IP addresses and network interfaces. |
| DHCP | Examining DHCP settings and lease information. |
| DNS | Checking DNS configuration and name resolution. |
| Routing | Examining routing tables and default gateways. |
| Network Connectivity | Verifying basic network connectivity. |

## Purpose

To develop practical networking knowledge through hands-on exercises, command-line tools, and technical documentation.
